# NoLimit Budget

Zero-based budgeting app with BANDGANG credit repair command center.

## Features

- **Today** — Income snapshot, operator reserves, recent activity, at-risk spending alerts
- **Budget** — Zero-based budget with paychecks, groups, and line items
- **Txns** — Transaction logging and filtering (all / income / spent)
- **BANDGANG** — Credit repair command center: score tracking, credit report upload, dispute letter drafting, action plan
- **Accounts** — Net worth tracker (assets & liabilities)
- **Stats** — Monthly spending breakdown, top expenses, 6-month history
- **PWA** — Works offline, installable on any phone
- **Local-only** — All data stays on your device (localStorage)
- **Export/Import** — Full backup as JSON
